### Developer Tools That Actually Work

We’re a small, focused team building the dev platform *we* always wanted. No fluff, no bloat — just powerful tools that make building fun again.


---

## 🔧 What We’re Building

Hexagonical is the all-in-one dev toolkit designed to get out of your way.

| Feature                | Status        | Description                                      |
| ---------------------- | ------------- | ------------------------------------------------ |
| **CLI**                | ⏳ Coming Soon | Zero-config dev environments & fast deployments  |
| **HackDB**             | 🛠 In Dev     | PostgreSQL-based DB with instant setup & backups |
| **Deployments**        | 🛠 In Dev     | Deploy with a single command — no config hell    |
| **Flows**        | 🛠 In Dev     | No hassle, No-code, way to interact with everything, in a nodebased editor!    |

## 🌍 Why We’re Doing This

We were sick of tools that made simple things hard. So we started building our own — tools that:

* Actually work out of the box
* Don’t need a PhD to use
* Are fun to use, not frustrating

> “We’re building the platform we always wished existed: powerful, simple, and not enterprise-bloated.”
